# Solitaire
Solitaire, a card game played often used alone has been made into an online version.
## Description
Toos and Languages Used: Java

This project leverages Java programming techniques learned in CS 31 to replicate a functional Solitaire game. The game incorporates principles of object-oriented programming (OOP), data structures, multithreading, and graphical user interface (GUI) development. The goal of this game is to organize the table piles sequentially and alternately. The deck pile can be used for cards and the suit piles are used to organize the cards. The implementation consists of six main classes: Solitaire.java, Card.java, CardPile.java, TablePile.java, DeckPile.java, and SuitPile.java.

## How to Play
There are 7 table piles that are initialized.  At the bottom, there is a new game to restart the game. There are four rectangles(decks) at the top left for the suit decks and two rectangles(one with cards and one with none) for the discard and deck pile. At the top it says “Solitaire Game”. When a card is clicked the card gets highlighted and can be moved to another located. Clicking through the deck pile puts them into the discard pile. The cards can be moved from the discard pile, from another deck, or to the empty piles.
